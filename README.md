**Solmar Bay** — an original open-world crime game in the spirit of GTA 6, built for make.fun's "Make GTA 6" bounty. Explore a sun-soaked coastal city on foot and by car, steal cars, outrun the Solmar Police Department across a 5-star wanted system, run taxi fares, hunt cash stashes, and play 8 story missions as Mara Solis fights to take the bay.

## Play it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network requests — every file the game loads lives under `game/`.

## Controls

- **WASD / Arrows** — move on foot, drive when in a car
- **Mouse** — aim · **Left click** — shoot · **R** — reload
- **E** — enter / steal a car, exit a car
- **Shift** — sprint · **Space** — handbrake
- **Esc** — pause · **M** — mute music · **F** — save game

## What's inside

- A 3600×3000 open city: downtown, old town, marina and beach, industrial east, hills — with traffic, pedestrians, parked cars and a lighthouse pier
- 5-star wanted system with SPD cruisers that chase and ram, and foot cops who shoot and arrest
- 8 story missions (drive, deliver, steal, shootout, chase, escape, bank job, final stand) with briefing, timers and rewards
- Taxi fares, 12 hidden cash stashes, save/load via localStorage
- Synthesized sound: engine, gunshots, sirens and a procedural music loop — no audio files
- HUD with minimap, health/armour, wanted stars, money and mission tracker

## Run it

```sh
node serve.ts
```
